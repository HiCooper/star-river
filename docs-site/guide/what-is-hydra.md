# 产品概述

## Hydra 是什么

Hydra 是一套自建的支付基础设施，包含两个核心服务：

| 服务 | 类比 | 定位 |
|------|------|------|
| **Hydra-Wall** | Superwall | 付费墙服务 |
| **Hydra-Pay** | Stripe | 统一支付网关 |

## 核心价值

### 降低研发成本

接入方无需：
- 自建付费墙 UI
- 对接多个支付渠道
- 处理各种支付渠道的验签、回调等复杂逻辑

只需调用 Hydra SDK，一行代码即可完成付费功能接入。

### 提升转化率

- 内置 A/B 测试框架，可测试不同付费墙设计
- 行为触发引擎，基于用户行为展示付费墙
- 免费试用、限时折扣等多种促销工具

### 统一用户体验

- 提供标准化付费流程
- 托管页面无需用户离开 App
- 支持多种支付渠道，用户选择偏好渠道

## 适用场景

### 场景一：快速上线付费功能

已有 App/网站，希望快速添加付费功能：
- 使用 Hydra-Wall 全托管模式
- 一行代码跳转付费墙页面
- 无需自建任何 UI

### 场景二：已有付费墙，只缺支付能力

已有自建付费墙 UI，只需要接入支付渠道：
- 只接入 Hydra-Pay
- 通过 SDK 或 API 创建支付
- 自己调用渠道完成支付

### 场景三：完全自建，集成支付能力

希望完全控制付费墙 UI，只使用 Hydra-Pay 的支付能力：
- 使用 Hydra-Pay API 模式
- 自己创建支付、获取 paymentUrl
- 自己实现跳转和回调处理
