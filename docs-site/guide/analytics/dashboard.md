# 数据看板

数据看板提供 Hydra 各产品线的核心业务指标可视化，帮助产品、运营团队实时掌握业务健康度。

## 概述

数据看板汇总了 hydra-wall（付费墙）和 hydra-pay（支付网关）的关键数据，提供统一的视图来监控收入、转化和用户行为。

## 核心指标

### 收入指标

| 指标 | 说明 |
|------|------|
| 总收入 (MRR) | 月度经常性收入 |
| 今日收入 | 当日结算金额 |
| 客单价 (ARPU) | 平均每笔订单金额 |
| 支付成功率 | 成功支付订单 / 总发起订单 |

### 转化漏斗

| 阶段 | 说明 |
|------|------|
| 曝光人数 | 付费墙展示给用户的数量 |
| 点击人数 | 用户点击了订阅/购买按钮 |
| 发起支付 | 用户进入支付流程 |
| 支付成功 | 完成付款并收到确认 |

### 付费墙指标

| 指标 | 说明 |
|------|------|
| 付费墙展示率 | 触发条件用户中实际展示比例 |
| 付费转化率 | 展示用户中完成付费的比例 |
| 实验组对比 | A/B 测试中各组转化率对比 |

## 看板布局

### 概览视图

顶部展示关键指标卡片：
- **今日收入** — 大字显示，带日环比变化
- **支付成功率** — 环形图 + 百分比
- **活跃订阅数** — 趋势线图

中部为时间筛选器，支持：
- 今天 / 昨天
- 最近 7 天 / 30 天
- 自定义日期范围

底部为趋势图区域。

### 趋势图

支持多指标叠加显示：
- 收入趋势（面积图）
- 转化率趋势（折线图）
- 用户增长趋势（柱状图）

图表支持：
- 鼠标悬停显示具体数值
- 点击拖拽放大时间范围
- 导出为 PNG 图片

### 分渠道视图

按支付渠道（Alipay / WeChat / Stripe / Apple IAP）分别展示：
- 各渠道收入占比
- 各渠道支付成功率
- 各渠道客单价对比

## 数据刷新

- **实时数据**: 每 5 分钟自动刷新
- **手动刷新**: 点击刷新按钮立即获取最新数据
- **数据延迟**: 支付数据约有 1-2 分钟延迟

## 权限说明

| 角色 | 可查看范围 |
|------|-----------|
| 管理员 | 所有指标，支持导出 |
| 运营 | 本产品线数据，支持导出 |
| 分析师 | 所有指标，不支持导出 |
| 查看者 | 基础指标，不支持时间细化 |

## 常见问题

**Q: 数据和实际收入有差异怎么办？**
A: 检查是否在结算周期内，部分渠道（如 Stripe）有结算延迟。

**Q: 可以自定义看板吗？**
A: 支持创建自定义视图，保存后可在「我的看板」中快速访问。

**Q: 数据可以 API 导出吗？**
A: 支持导出为 CSV 或通过 REST API 获取。
