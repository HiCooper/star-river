# 架构决策记录 (ADR)

本文档记录 Hydra 项目的重要架构决策。

## 记录格式

每个 ADR 包含：

- **编号**: ADR-XXX
- **标题**: 简短的描述性标题
- **状态**: 提出中 / 已接受 / 已废弃 / 已替代
- **背景**: 描述做出该决策的上下文
- **决策**: 描述最终的决定
- **后果**: 该决策的影响（正面和负面）
